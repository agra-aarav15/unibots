# Hello world plugin

A minimal Unibots plugin: a manifest and one skill. Copy this folder to start your own, then read
[Build a plugin](https://github.com/agra-aarav15/unibots/blob/main/docs/build-a-plugin.md).

For hosted tools, start with the [MCP server example](../mcp-server/README.md).

To try your copy, open **Integrations** → **+** → **From GitHub**, paste your public
repository or plugin folder URL, choose **Preview**, then **Add**.
